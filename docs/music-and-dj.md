# Music production and DJ setup

The personal profile installs Apple-distributed apps such as Logic Pro,
GarageBand, djay Pro, and Neural Mix Pro through the App Store.

Many professional music and DJ applications are distributed directly by their
vendors and require a license, account sign-in, hardware activation, or a
vendor-specific installer. Install these manually after setup from official
vendor sites: Rekordbox, Serato DJ, Traktor, Ableton Live, Bitwig, Native
Access, and controller drivers from Pioneer/AlphaTheta, Denon DJ, RANE, Akai,
Novation, or other hardware vendors.

Install the audio-routing tool you actually use (for example BlackHole or
Loopback) from its official source, then grant macOS microphone/audio
permissions and verify it in Audio MIDI Setup.

If a vendor later publishes a stable Homebrew cask, add only its cask name to
the personal manifest. Never commit license files, activation tokens, vendor
credentials, or downloaded installers.
